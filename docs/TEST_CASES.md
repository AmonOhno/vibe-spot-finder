# E2E テストケース

- 実装: `e2e/*.spec.ts`（テストタイトル先頭の `TC-xx` が本表の ID と 1 対 1 で対応）
- 操作動画: `e2e/recordings/TC-xx.webm`（一覧は [e2e/recordings/README.md](../e2e/recordings/README.md)）
- フィクスチャ: `e2e/fixtures/`（`npm run fixtures` で再生成）
- 仕様の参照先: [SPEC.md](./SPEC.md) の機能 ID（F-xx）/ 非機能 ID（N-xx）

## テストケース

### ファイル入力（`e2e/upload.spec.ts`）

| ID | 対応仕様 | テストケース | 前提・手順 | 期待結果 |
|---|---|---|---|---|
| TC-01 | §2 | 初期表示でアップロードエリアのみが表示される | 1. トップを開く | タイトル「Vibe Spot Finder」、ドロップゾーン、有効な「ファイルを選択」、プライバシー注記が表示される。プレビュー・解析結果・スポットは表示されない |
| TC-02 | F-01, F-04 | ファイル選択で画像のプレビューが表示される | 1. 「ファイルを選択」→ `ocean.png` | プレビュー画像、ファイル名、「画像」バッジ、有効な「雰囲気を解析する」「クリア」が表示される |
| TC-03 | F-02, F-04 | ドラッグ＆ドロップで動画を選択できる | 1. ドロップゾーンに `ocean.webm` をドロップ | ファイル名、`<video>` プレビュー、「動画」バッジが表示される |
| TC-04 | F-03 | 非対応形式のファイルはエラーになる | 1. 「ファイルを選択」→ `not-media.txt` | `role=alert` で「対応していないファイル形式です…」が表示され、プレビューは表示されない |
| TC-05 | F-03 | サイズ上限を超える画像はエラーになる | 1. 20MB + 1byte の `image/png` をドロップ | 「画像ファイルは 20MB 以下にしてください」が表示され、プレビューは表示されない |
| TC-06 | F-11 | クリアで初期状態に戻る | 1. `ocean.png` を選択し解析 2. 「クリア」 | プレビュー・解析結果・スポット一覧が消える |

| TC-09 | F-05 | 夜景の画像は「夜景・ネオン」と判定される | 1. `night.png` を選択 2. 解析 | 先頭が「夜景・ネオン」、1 位スポットの一致理由に「夜景・ネオン」 |
| TC-10 | F-05 | 夕焼けの画像（WebP）は「夕焼け・ノスタルジック」と判定される | 1. `sunset.webp` を選択 2. 解析 | 先頭が「夕焼け・ノスタルジック」、1 位スポットの一致理由に同 Vibe |
